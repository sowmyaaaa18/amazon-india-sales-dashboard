# Amazon India Sales Analysis Dashboard

## Project Overview
An interactive Power BI dashboard to analyze Amazon India sales data and generate useful business insights.

## Tools Used
- Microsoft Power BI
- Microsoft Excel
- DAX

## Dashboard Pages
1. Overall Sales & Profit Performance
2. Order & Operations Analysis
3. Payment & Fulfillment Analysis

## Key Metrics
- Total Sales
- Total Profit
- Total Orders
- Total Units Sold
- Average Order Value
- Profit Margin
- Return Rate
- Cancellation Rate

## Project Objectives
- Analyze sales and profit trends.
- Identify top-performing products and categories.
- Monitor order returns and cancellations.
- Analyze payment and fulfillment methods.
- Compare state-wise sales performance.
